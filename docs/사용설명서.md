# 시간표 짜기 사용 설명서

이 문서는 앱 안의 「도움말 → 사용 설명서」와 같은 내용입니다. 처음 쓰시는 분은 순서대로 읽어 보시길 권합니다.

## 1. 소개

「시간표 짜기」는 초등학교의 전담 시간표를 자동으로 배정하고 손으로 다듬는 프로그램입니다. 교사·과목·반·주당 시수를 표로 적으면, 같은 반에 수업이 겹치지 않고 교사가 한 시각에 두 반에 들어가지 않도록 시간표를 만들어 줍니다.

작업은 크게 세 걸음입니다. 먼저 학교의 바탕 자료(시간 틀·반·교사·과목·특별실)와 시수표를 채웁니다. 다음으로 「자동 배정」이 시수표를 바탕으로 시간표 후보 여러 장을 만들면, 그 가운데 하나를 고릅니다. 마지막으로 「점검」과 「직접 조정」으로 다듬어 인쇄합니다.

<!-- figure:flow -->

교무 업무를 맡은 선생님이 사전 지식 없이 쓸 수 있도록 만들었습니다. 어려운 낱말은 화면 안에서 밑줄로 뜻을 볼 수 있고, 이 설명서 마지막 「11. 용어」에도 정리해 두었습니다.

## 2. 시작하기

- **웹 주소로 열기**: 인터넷 브라우저에서 배포 주소를 엽니다. 설치가 필요 없습니다.
- **폰 홈 화면에 추가**: 휴대전화 브라우저에서 연 뒤 「홈 화면에 추가」를 누르면 앱처럼 쓸 수 있습니다.
- **설치본 첫 실행 경고 처리**: 내려받은 설치본을 처음 열 때 경고가 뜰 수 있습니다. 윈도우에서는 「추가 정보 → 실행」을, 맥에서는 파일을 「우클릭 → 열기」를 누르면 실행됩니다.
- **처음이라면 둘러보기**: 첫 화면에서 「샘플 학교로 둘러보기」를 누르면 자료가 채워진 예제로 전체 흐름을 먼저 볼 수 있습니다. 실제 자료를 넣을 때는 「새 학교 만들기」로 시작합니다.

## 3. 화면 읽는 법

작업을 시작하기 전에 화면이 어떻게 나뉘어 있는지 알아 두면 헤매지 않습니다.

### 상단 바

화면 맨 위에는 프로그램 이름과 함께 저장·도움말 단추가 있습니다. 「저장」으로 지금까지 한 작업을 파일로 내려받고, `?` 단추로 도움말 서랍을 엽니다. 밝은 화면과 어두운 화면을 바꾸는 단추(해·달 모양)도 여기에 있습니다.

### 왼쪽 7단계 탭

화면 왼쪽에는 「기초자료 · 고정·금지 · 자동 배정 · 점검 · 직접 조정 · 시안 · 인쇄·내보내기」 일곱 단계가 위에서 아래로 있습니다. 위에서부터 차례로 밟으면 됩니다. 각 탭에는 어디까지 되었는지 배지가 붙습니다.

### 상태줄

화면 맨 아래 상태줄은 지금 시간표의 상태를 요약합니다. 「필수 위반」 건수, 「권장 점수」, 배정된 수업 수가 나란히 나옵니다. 「필수 위반」이 0이라야 성립하는 시간표이고, 「권장 점수」는 낮을수록 좋습니다. 자동 배정을 하기 전에는 「아직 배정 전」으로 나옵니다.

<!-- figure:status-bar -->

### 색의 뜻

화면에서 색은 세 가지 뜻으로만 씁니다. 초록은 좋음(옮길 수 있음·완료), 노랑은 주의(권장 규칙에 걸림), 빨강은 필수 규칙 위반입니다. 흑백으로 인쇄하면 색은 빠지고 글자와 표로만 나옵니다.

### ⓘ 단추와 밑줄 낱말

화면 곳곳의 `ⓘ` 단추를 누르면 그 자리에 대한 설명이 뜹니다. 설명에는 개념·사용 예·고치는 곳이 함께 들어 있습니다. 점선 밑줄이 그어진 낱말(필수 규칙·시간 틀·시안 등)을 누르면 한 줄 뜻과 예가 나옵니다.

### 도움말 서랍 네 탭

상단 `?`를 누르면 오른쪽에 도움말 서랍이 열립니다. 네 탭으로 나뉩니다.

- **이 화면**: 지금 보고 있는 화면의 개념·순서·사용 예·자주 하는 실수.
- **용어**: 낱말을 검색해 뜻과 예를 봅니다.
- **사용법**: 조작이 화면에서 어떻게 움직이는지 움직이는 예로 봅니다.
- **사용 설명서**: 이 문서 전체를 그대로 읽습니다.

## 4. 작업 순서 7단계

일곱 단계를 위에서 아래로 차례로 밟습니다. 단계마다 개념·순서·사용 예·확인할 것을 적었습니다.

### 4-1. 기초자료

**개념**: 자동 배정이 시간표를 짜려면 먼저 학교의 바탕 자료가 있어야 합니다. 하루가 몇 교시인지, 어떤 반과 교사와 과목이 있는지, 그리고 누가 어느 반에 무엇을 주 몇 시간 하는지를 여기서 정합니다. 이 가운데 시수표가 자동 배정의 유일한 입력입니다.

**순서**:

1. 「시간 틀」을 학년군마다 하나씩 만듭니다(교시 수와 점심 시각).
2. 「반」에 학년·반을 넣고 「담임 이름」을 적습니다.
3. 「교사」에 전담·강사를 넣습니다.
4. 「과목」과 「특별실」을 채웁니다.
5. 「시수표」에 교사·과목·반·주당 시수를 적습니다.

**사용 예**: 5·6학년 시간 틀을 6교시로 만들고 6-1·6-2·6-3 반을 넣습니다. 가람 선생님 영어 6학년 세 반 주 3시간을 시수표에 적으면 세 줄로 펼쳐져 시간표 아홉 칸이 됩니다.

**확인할 것**: 시간 틀을 먼저 만들었는지, 시수표가 비어 있지 않은지 봅니다. 시간 틀이 없으면 시각이 없어 겹침을 판정할 수 없습니다.

<!-- figure:demand-row -->

### 4-2. 고정·금지

**개념**: 수업을 넣으면 안 되는 시간(부장회의·타교 출강)과 미리 자리가 정해진 수업(창체·동아리)을 자동 배정에 미리 알려 두는 단계입니다. 필요할 때만 쓰므로 없는 학교는 넘어가도 됩니다.

**순서**:

1. 위에서 대상(반·교사·특별실)을 고릅니다.
2. 막을 칸을 눌러 「배정 불가 → 되도록 피함 → 임시 불가」를 돌려 가며 표시합니다.
3. 창체·동아리 같은 수업은 반을 고르고 「고정 수업」으로 그 칸에 넣습니다.
4. 작업이 끝나면 「임시 불가 모두 해제」로 임시 표시를 한꺼번에 풉니다.

**사용 예**: 교사 「가람」을 고르고 월요일 1교시 칸을 눌러 부장회의 시간을 「배정 불가」로 만듭니다. 6-1을 고르고 목요일 5교시에 창체를 「고정 수업」으로 넣습니다.

**확인할 것**: 교사·특별실의 표시는 교시가 아니라 시각으로 저장됩니다. 「배정 불가」는 절대 넣지 않는 칸, 「되도록 피함」은 점수만 붙는 칸입니다.

### 4-3. 자동 배정

**개념**: 시수표에 적은 수업을 규칙을 지키며 격자에 채워 넣습니다. 한 번에 여러 장의 「시간표 후보」를 만들어, 사람이 필수 위반과 권장 점수를 보고 하나를 고르게 합니다.

**순서**:

1. 「후보 수」와 「후보당 계산 시간」을 정합니다(기본값으로도 충분합니다).
2. 「자동 배정 시작」을 누르고 잠시 기다립니다.
3. 후보 카드에서 「필수 위반」·「권장 점수」·「미배정」을 봅니다.
4. 「추천」 배지나 마음에 드는 후보를 골라 「이 후보로 진행」을 누릅니다.

**사용 예**: 「후보 수」 4, 「후보당 계산 시간」 10초로 두면 40초쯤 뒤 후보 네 장이 나옵니다. 필수 위반 0·권장 점수 4,800인 「추천」 후보를 골라 적용합니다.

**확인할 것**: 위에 경고 카드가 뜨면 시수표가 도저히 풀리지 않는 상태입니다. 「미배정」이 남은 후보는 시수 전부를 넣지 못한 것입니다.

### 4-4. 점검

**개념**: 완성한 시간표가 규칙을 다 지켰는지 규칙마다 세어 보여 줍니다. 「필수 위반」은 반드시 0이 되어야 하고, 「권장 점수」는 낮을수록 좋습니다.

**순서**:

1. 맨 위 「필수 위반」과 「권장 점수」를 확인합니다.
2. 규칙 행을 눌러 어느 칸이 문제인지 목록으로 봅니다.
3. 목록의 항목을 눌러 「직접 조정」 화면으로 건너가 그 칸을 손봅니다.
4. 「자동 개선」으로 지금 시간표를 유지하며 위반만 줄입니다.

**사용 예**: 「같은 반 겹침」 행에 2가 보이면 한 반에 수업이 두 개 겹친 곳이 두 군데입니다. 행을 누르면 6-2 목요일 2교시처럼 문제 칸이 목록으로 열립니다.

**확인할 것**: 더 개선되지 않는다고 잘못된 것이 아닙니다. 어쩔 수 없는 위반은 「조정할 수 있는 항목만」을 켜 가립니다.

### 4-5. 직접 조정

**개념**: 자동 배정이 만든 시간표를 사람이 손으로 고치는 단계입니다. 옮기기 전에 규칙이 어떻게 바뀌는지 미리 보여 주고, 필수 규칙을 어기는 이동은 잠급니다.

**순서**:

1. 칸을 한 번 눌러 수업을 「선택」합니다.
2. 초록·노란 칸 가운데 옮길 칸을 누릅니다.
3. 「이동 미리보기」에서 규칙이 어떻게 바뀌는지 확인합니다.
4. 필수 규칙이 깨지지 않으면 「이동」으로 옮깁니다.
5. 그 자리에 두고 싶은 수업은 「잠금」을 걸어 둡니다.

**사용 예**: 한결 선생님(체육) 6-2 화요일 3교시를 누르면 갈 수 있는 칸이 초록으로 켜집니다. 노란 칸으로 옮기면 권장 점수가 오르고, 빨간 칸은 필수 규칙을 어겨 잠깁니다.

**확인할 것**: 빨강 칸으로는 옮길 수 없습니다. 갈 수 있는 칸이 하나도 없으면 화면 위 안내가 가장 많이 걸린 규칙을 알려 줍니다.

### 4-6. 시안

**개념**: 시간표를 여러 가지로 만들어 보고 그중 가장 나은 것을 고르는 단계입니다. 이름 붙여 보관한 것을 「시안」, 배부할 것으로 정한 것을 「확정본」이라 합니다.

**순서**:

1. 이름을 적고 「시안 저장」으로 지금 상태를 보관합니다.
2. 수업을 더 손본 뒤 다른 이름으로 또 「시안 저장」을 합니다.
3. 여러 시안을 비교해 가장 나은 것을 고릅니다.
4. 배부할 것을 「확정본으로 지정」합니다.

**사용 예**: 「1차 시안」을 저장하고 수업을 몇 개 옮긴 뒤 「부장 회의 반영」으로 다시 저장합니다. 「부장 회의 반영」이 가장 나으면 「확정본으로 지정」해 둡니다.

**확인할 것**: 자동 배정·자동 개선 때 「자동 보관」 시안이 저절로 쌓입니다. 「이 시안으로 되돌리기」로 언제든 이전 상태로 돌아갈 수 있습니다.

### 4-7. 인쇄·내보내기

**개념**: 완성한 시간표를 종이나 파일로 꺼내는 단계입니다. 보는 사람에 따라 「반별」·「교사별」·「특별실별」 세 가지로 볼 수 있습니다.

**순서**:

1. 보기(「반별」·「교사별」·「특별실별」)를 고릅니다.
2. 「인쇄」로 종이에 뽑습니다.
3. 엑셀이 필요하면 「엑셀로 내보내기」로 파일을 만듭니다.
4. 다른 컴퓨터에서 다시 열려면 「작업 파일로 저장」을 씁니다.

**사용 예**: 「반별」을 고르면 6-1·6-2·6-3 반마다 한 장씩 시간표가 나옵니다. 「교사별」을 고르면 가람 선생님(영어)의 주간 수업만 모아 인쇄할 수 있습니다.

**확인할 것**: 인쇄·내보내기는 확정본을 기준으로 합니다. 배부 전에 어느 시안이 확정본인지 확인하세요.

## 5. 담임과 전담을 적는 법

이 프로그램에서 **담임은 사람이 아니라 반의 속성**입니다. 담임을 교사 명부에 넣지 않습니다. 반의 빈 칸이 곧 담임 수업입니다.

<!-- figure:homeroom -->

- **담임은 반의 속성**: 반 탭의 「담임 이름」에 이름만 적습니다. 예를 들어 6-1은 슬기, 6-2는 푸름이라고 적으면 인쇄물에 담임 이름이 붙습니다. 전담 수업이 놓이고 남은 빈 칸은 모두 그 반 담임의 수업으로 봅니다.
- **특별실 담임 수업**: 담임이 체육관·컴퓨터실처럼 특별실이 필요한 수업을 할 때만, 시수표에서 교사를 「담임」으로 골라 한 줄 적습니다. 교실에서 하는 담임 수업은 따로 적지 않아도 됩니다.
- **담임 겸 전담**: 자기 반 담임이면서 다른 반 전담도 맡는 분은 교사 탭에 사람으로 넣고 「담임반」을 연결합니다. 예를 들어 슬기 선생님이 6-1 담임이면서 6-2 음악도 맡으면 「담임 겸 전담」으로 넣고 「담임반」에 6-1을 연결합니다.

전담 수업이 놓인 뒤 남은 칸이 담임 수업으로 차오르는 모습은 아래에서 볼 수 있습니다.

## 6. 시수표 엑셀로 넣기

이미 엑셀로 만든 시수표가 있으면 그대로 넣을 수 있습니다. 기초자료의 시수표에서 「엑셀에서 불러오기」를 누르고 파일을 고릅니다. 빈 서식이 필요하면 「시수표 엑셀 내려받기」로 서식을 받아 채운 뒤 다시 넣으세요. 엑셀에서 범위를 복사해 시수표 첫 칸에 붙여도 여러 줄이 한 번에 들어갑니다.

| 5 | 주당 시수 | 3 |

담임이 하는 특별실 수업은 교사 열에 「담임」이라고 적습니다.

## 7. 저장과 파일

<!-- figure:work-file -->

- **작업 파일**: 학교 하나의 자료·시간표·시안 전부를 담은 파일입니다(`.shiftgrid.json`). 다른 컴퓨터에서 열 수 있으니 중요한 작업은 꼭 내려받아 두세요.
- **브라우저 자동 저장의 한계**: 웹에서는 이 브라우저에만 자동으로 저장됩니다. 브라우저 자료를 지우면 사라지므로 작업 파일로 내려받아 보관해야 합니다.
- **이어서 작업하기**: 내려받은 작업 파일은 첫 화면의 「파일 열기」로 다시 불러옵니다. 학교에서 내려받아 집에서 이어 작업할 수 있습니다.
- **시안과 확정본**: 시안은 언제든 되돌릴 수 있는 보관본이고, 확정본은 그 가운데 배부할 것으로 정한 시안입니다. 시안은 작업 파일 안에 함께 담깁니다.

## 8. 의견 보내기

오른쪽 아래 「의견 보내기」를 누르면 개선 요청·오류 제보를 바로 보낼 수 있습니다. 어느 화면에서 눌렀는지가 자동으로 붙고, 「화면 캡처」·「파일 첨부」·Ctrl+V 붙여넣기로 그림을 최대 4장 넣을 수 있습니다. 학교 자료(시수표·이름)는 보내지지 않습니다. 온라인으로 보내지 못하면 제보문이 파일로 내려오니, 그 파일을 담당자에게 메신저나 메일로 보내 주세요.

## 9. 자주 묻는 질문

- **필수 위반이 0이 되지 않습니다**: 시수표가 도저히 풀리지 않는 경우입니다. 한 교사의 주당 시수가 들어갈 수 있는 칸보다 많으면 어떤 방법으로도 0이 되지 않습니다. 담당 반을 나누거나 시수를 줄이세요.
- **자동 배정 화면에 경고가 뜹니다**: 자동 배정 전 「사전 점검」이 못 푸는 시수표를 미리 알려 준 것입니다. 안내대로 기초자료를 고치세요.
- **옮길 곳이 없습니다**: 직접 조정에서 어떤 수업을 옮길 초록·노랑 칸이 하나도 없으면, 화면 위 안내가 가장 많이 걸린 규칙을 알려 줍니다. 먼저 관련 수업을 옮기거나 규칙 설정을 확인하세요.
- **담임을 어디에 넣나요**: 담임은 교사 명부에 넣지 않습니다. 반 탭의 「담임 이름」에 이름만 적고, 특별실이 필요한 담임 수업만 시수표에 「담임」으로 적습니다.
- **미배정이 남았습니다**: 자동 배정 뒤에도 미배정이 남으면 그만큼 칸이 모자란 것입니다. 담당 반이나 시수를 줄이거나, 금지 칸을 풀어 자리를 만든 뒤 다시 자동 배정하세요.
- **같은 3교시인데 왜 겹치지 않나요**: 학년마다 교시의 실제 시각이 다릅니다. 1·2학년 3교시와 5·6학년 3교시가 다른 시각이면 한 교사가 둘을 맡아도 겹치지 않습니다. 겹침은 교시 번호가 아니라 시각으로 봅니다.
- **자동 배정을 다시 눌렀더니 손본 것이 사라졌습니다**: 「자동 보관」 시안으로 이전 상태로 되돌릴 수 있습니다. 손본 수업은 다음부터 「잠금」을 걸어 두면 다시 돌려도 그 자리에 남습니다.
- **작업이 사라질까 걱정됩니다**: 상단 「저장」으로 작업 파일을 내려받아 두세요. 브라우저 자동 저장은 이 브라우저에만 남습니다.
- **화면이 너무 어둡습니다**: 상단 바의 해·달 모양 단추로 밝은 화면으로 바꿀 수 있습니다.
- **한 칸에 두 수업이 보입니다**: 함께 수업이거나 겹침입니다. 겹침이면 필수 색 테두리가 붙습니다. 「점검」에서 어느 규칙에 걸렸는지 확인하세요.

## 10. 자주 하는 실수

- **담임을 교사로 넣기**: 담임은 반의 속성입니다. 교사 명부에 담임을 넣으면 반의 빈 칸 계산이 어긋납니다.
- **시간 틀 없이 반부터 만들기**: 시각이 없어 겹침을 판정할 수 없습니다. 시간 틀을 먼저 만드세요.
- **교실 담임 수업까지 시수표에 적기**: 특별실이 필요한 담임 수업만 적습니다. 교실 수업은 빈 칸이 알아서 담임 수업이 됩니다.
- **「배정 불가」와 「되도록 피함」을 섞어 쓰기**: 「배정 불가」는 절대 넣지 않는 칸, 「되도록 피함」은 점수만 붙는 칸입니다. 뜻이 다릅니다.
- **저장 없이 브라우저 닫기**: 작업 파일로 내려받지 않으면 다른 컴퓨터에서 열 수 없습니다.
- **확정본을 정하지 않고 인쇄하기**: 인쇄는 확정본을 기준으로 합니다. 배부 전에 확정본을 확인하세요.

## 11. 용어

자세한 뜻과 예는 도움말의 「용어」 탭에서도 볼 수 있습니다.

| 낱말 | 뜻 |
| --- | --- |
| 필수 규칙 | 반드시 지켜야 하는 규칙입니다. 하나라도 어기면 시간표가 성립하지 않습니다. |
| 권장 규칙 | 되도록 지키면 좋은 규칙입니다. 어긴 정도를 점수로 보여 주고 낮을수록 좋습니다. |
| 시간 틀 | 하루의 교시 수·수업 시각·점심 위치를 정한 틀입니다. 학년군마다 하나씩 둡니다. |
| 시수표 | 교사·과목·반·주당 시수를 적는 표로, 자동 배정의 유일한 입력입니다. |
| 담임 | 사람이 아니라 반의 속성입니다. 반의 빈 칸은 모두 담임 수업으로 봅니다. |
| 담임 겸 전담 | 자기 반 담임이면서 다른 반 전담도 맡는 교사입니다. |
| 우선순위 | 교사의 희망을 얼마나 무겁게 볼지 정하는 등급입니다(1 부장·보직, 2 일반, 3 강사·지원인력). |
| 함께 수업 | 두 교사가 한 반 한 칸에 함께 들어가는 수업입니다. |
| 연속 수업 | 같은 날 붙여서 하는 수업입니다(「2」는 2시간 연속). |
| 차시 순서 맞춤 | 모든 반이 1차시를 마친 뒤에 2차시를 시작하게 맞춥니다. |
| 배정 불가·되도록 피함·임시 불가 | 특정 요일·시각에 수업을 막거나 피하도록 칸에 다는 표시입니다. |
| 고정 수업 | 창체·동아리처럼 반의 칸을 미리 차지하는 수업입니다. 자동 배정이 건너뜁니다. |
| 잠금 | 정한 수업을 자동 배정이 옮기지 못하게 그 자리에 묶어 둡니다. |
| 시간표 후보 | 자동 배정이 만든 시간표 여러 장입니다. 그중 하나를 고릅니다. |
| 후보당 계산 시간 | 후보 한 장을 만드는 데 쓰는 시간(초)입니다. |
| 미배정 | 시수표에 적었지만 아직 시간표에 놓이지 않은 시간입니다. |
| 자동 개선 | 지금 시간표를 유지하면서 규칙 위반만 줄입니다. |
| 조정할 수 있는 항목 | 사람이 옮겨서 해결할 여지가 있는 위반입니다. |
| 시안 | 지금 시간표를 이름 붙여 보관한 것입니다. |
| 확정본 | 여러 시안 가운데 배부할 것으로 정한 시안입니다. |
| 작업 파일 | 학교 하나의 자료·시간표·시안 전부를 담은 파일(`.shiftgrid.json`)입니다. |
| 수용 수 | 특별실에 같은 시각에 들어갈 수 있는 반의 수입니다. |
| 점심 기준 | 이 교사가 점심을 맞춰야 하는 시간 틀입니다. |
| 교시와 시각 | 교시는 순서 번호, 시각은 실제 시계 시간입니다. 겹침은 시각으로 봅니다. |
| 자동 보관 시안 | 크게 바뀔 때 저절로 쌓이는 시안입니다. |
| 사전 점검 | 자동 배정 전에 시수표가 풀 수 없는 상태인지 미리 알려 주는 경고입니다. |
| 고정 수업과 잠금의 차이 | 고정 수업은 미리 칸에 넣는 수업, 잠금은 놓인 수업을 묶어 두는 것입니다. |
| 남음·초과·완료 | 시수표 각 줄의 수업이 얼마나 들어갔는지 보여 주는 표시입니다. |
| 특별실 사용 시수 | 한 줄에서 특별실을 써야 하는 시간 수입니다. |
| 적용 학년 | 이 시간 틀을 어느 학년이 쓰는지 정하는 값입니다. |
