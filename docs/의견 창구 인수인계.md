# 의견 창구 인수인계 — 담당자가 바뀌어도 돌아가게

앱 오른쪽 아래 「의견 보내기」는 두 길로 움직입니다. **길 1이 막혀도 길 2는 항상 됩니다.**

| 길 | 무엇 | 필요한 것 |
|---|---|---|
| 1. 온라인 | 앱 → 중계(Cloudflare Worker) → GitHub 이슈 자동 생성(캡처 포함) | 아래 「비밀값 3개」 |
| 2. 파일 | 중계가 없거나 실패하면 제보문+캡처를 HTML 파일 하나로 내려줌. 사용자가 메신저·메일로 보냄 | 없음 |

## 어디에 무엇이 사나

- 중계 코드: `feedback-worker/worker.js` (+ `wrangler.toml`) — 이 저장소 안. 특정 사람의 계정에 묶이지 않습니다.
- 배포: `.github/workflows/feedback-worker.yml` — `feedback-worker/`가 바뀌어 `main`에 올라가면 GitHub Actions가 자동으로 다시 배포합니다.
- 앱 쪽 주소: `src/ui/feedback/config.ts`의 `FEEDBACK_URL` 한 줄.
- 이슈·캡처가 모이는 곳: `wrangler.toml`의 `GITHUB_REPO` (기본 `2026-gne-dev-task-force-team/school-shiftgrid-feedback`). **비공개 저장소를 권합니다** — 캡처에 교사 실명이 보일 수 있습니다.

## 처음 켜기 (또는 후임이 이어받기) — 20분

1. **이슈 저장소** 만들기: GitHub 조직에 비공개 저장소 `school-shiftgrid-feedback`을 만듭니다(빈 저장소, README 하나).
2. **GitHub 토큰**: 조직 관리자 계정 → Settings → Developer settings → Fine-grained tokens → 새 토큰.
   - Repository access: 위 저장소만
   - Permissions: **Issues: Read and write** · **Contents: Read and write**
   - 만료는 1년. 만료되면 이 절차로 다시 만들어 3번의 `FEEDBACK_GITHUB_TOKEN`만 갈아 끼웁니다.
3. **Cloudflare 계정**(무료): 조직 공용 메일로 가입을 권합니다. 대시보드에서
   - 계정 ID (오른쪽 「계정 ID」)
   - API 토큰: 「내 프로필 → API 토큰 → 토큰 생성 → 템플릿 *Edit Cloudflare Workers*」
4. **저장소 비밀값**: 이 저장소 → Settings → Secrets and variables → Actions
   - Secrets: `CLOUDFLARE_API_TOKEN` · `CLOUDFLARE_ACCOUNT_ID` · `FEEDBACK_GITHUB_TOKEN`
   - Variables: `FEEDBACK_WORKER_ENABLED` = `true`
5. Actions 탭에서 「Deploy feedback worker」를 **Run workflow**로 한 번 돌립니다. 끝나면 로그에 Worker 주소가 나옵니다(`https://shiftgrid-feedback.<계정이름>.workers.dev`).
6. 그 주소를 `src/ui/feedback/config.ts`의 `FEEDBACK_URL`에 넣고 커밋·푸시합니다. Pages가 다시 배포되면 길 1이 켜집니다.

확인: 브라우저에서 Worker 주소를 열면 `{"ok":true,"service":"shiftgrid-feedback",...}`가 보여야 합니다. 앱에서 시험 제보를 하나 보내 이슈가 생기는지 봅니다.

## 끄기·바꾸기

- 온라인 길만 끄려면 `FEEDBACK_WORKER_ENABLED`를 `false`로 하고 `FEEDBACK_URL`을 빈 문자열로. 앱은 곧바로 길 2로 갑니다.
- 이슈 저장소를 바꾸려면 `wrangler.toml`의 `GITHUB_REPO`와 토큰의 저장소 범위를 함께 바꿉니다.
- 앱 주소가 바뀌면 `wrangler.toml`의 `ALLOWED_ORIGINS`에 새 주소를 넣습니다(안 넣으면 403).

## 왜 이렇게 만들었나

- 선생님들은 GitHub 계정이 없습니다. 브라우저 앱에 토큰을 넣으면 누구나 꺼내 쓸 수 있으므로 토큰은 중계에만 둡니다.
- 중계·배포·문서가 전부 이 저장소에 있어, 담당자가 떠나도 후임이 비밀값만 다시 넣으면 그대로 돕니다.
- 중계가 죽어도 창구가 죽지 않도록 파일 내려받기 길을 항상 남겼습니다.
