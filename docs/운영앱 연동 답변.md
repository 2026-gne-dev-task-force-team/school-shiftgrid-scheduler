## 2. 이번에 고친 것

검토 결과: 빠진 자리 없음. 코드 변경은 추가로 하지 않았다.

- ① 고정 배치(`fixed`)를 권장 규칙 감점에서 제외 — 소프트 14개 전부 확인:
  - `avoid`(`rules.ts:504`) · `same-period-across-days`(`:698`) · `subject-adjacent`(`:725`): 이번에 `a.fixed` 건너뛰기 추가.
  - `consecutive-limit` · `prefer-consecutive` · `compact-day` · `subjects-per-day-agent` · `am-pm-balance` · `one-place-per-day` · `lunch-adjacent` · `day-cluster` · `day-load-balance`: 원래부터 `agentSoftDays`/`agentSoftAll`(`:90-101`)을 거쳐 fixed 가 빠진다.
  - `subjects-per-day-track`(`:644`) · `priority-early`(`:867`): 원래 fixed 제외.
- ② schemaVersion — `src/store/doc-ops.ts:24` setMeta 2→3. `grep -rn schemaVersion src` 로 전수 확인: 불러오기·새 문서·마이그레이션·내보내기는 모두 3. 남은 `2` 는 시험 보조 파일 `src/engine/__fixtures__/small.ts:44` 하나(앱 코드 아님, 마이그레이션 입력 겸용이라 그대로 둠).

## 3. v2 에서 이 구조를 유지하려면

- 확정본 내보내기는 **schemaVersion 3 JSON 한 파일**로 유지한다 (Doc 전체 직렬화). 필드 이름·뜻을 바꾸면 운영 앱이 거절하므로 바꿀 땐 판수를 올리고 먼저 알린다.
- fixed 는 감점 계산에서만 빠지고, 칸을 먹는 하드 규칙(겹침·금지칸)에는 계속 걸린다 — 이 구분도 유지.

## 4. 남은 것

- 운영 앱 쪽에서 받은 **샘플 JSON 재요청** — 위 대조는 타입·생성 코드 기준이지 실제 파일 대조가 아니다.
- **계약 검사 스크립트**를 받으면 CI 에 건다.
- `agents.attr.직무` 가 필수인지 확인 요청 (필수면 내보내기에서 `role` 복사 추가).
- 학기 날짜(`timetables.startDate/endDate`)를 운영 앱이 신뢰하는지 확인.
