# _참고 — 옛 코드 (갈아엎음, 2026-10-31)

> 쥔님 지시: "V2는 일단 이것도 갈아엎는 걸로 하자. 그냥 뭐 참고만 하게 그냥 어디다가 박아 놔버리고
> 새로운 V2 폴더를 따로 만들도록 하자." 여기는 그 "박아 놓은" 자리다.

🔴 **이 폴더는 빌드·타입검사·테스트·린트 대상에서 전부 빠져 있다** (`tsconfig.app.json` exclude ·
`vitest.config.ts` exclude · `.oxlintrc.json` ignorePatterns). 폴더 안 상대경로 import 는
이사 과정에서 끊어진 곳도 있다 — **그대로 실행되는 코드가 아니라 눈으로 읽는 참고용**이다.

- `옛-v1/` — 2026-07~10월, 김은지 선생님이 실제로 쓰시는 `v1` 브랜치와 같은 계통의 Electron 판 코드.
  `engine`(엔진·솔버) · `io`(엑셀 왕복) · `platform`(Electron/웹 플랫폼 계약) · `store` · `types`(스키마) ·
  `ui`(화면 전체) · `App.tsx` · `assets`.
- `옛-v2/` — main 브랜치에서 작업하던 "표가 먼저" 재설계판(v2.0.0-m2.0, 2026-10). `src/v2/` 를 통째로 옮겼다.

## 끌어다 쓸 값어치가 있는 것 (새로 짤 때 참고)

- **`옛-v1/engine/`** (3,121줄) — 규칙 엔진·배정 솔버. 시간표 제약(교사 금지칸·협력수업·담임 등)을
  어떻게 모델링하고 풀었는지가 여기 전부 있다. 새 엔진을 설계할 때 가장 먼저 열어볼 자리.
- **`옛-v1/ui/parts/Sheet.tsx`** (858줄) — 엑셀식 편집 격자(셀 선택·드래그·복사붙여넣기·키보드 이동).
  표 컴포넌트를 다시 짤 때 상호작용 디테일을 참고.
- **`옛-v2/rows.ts`** — 시간표 "행"의 시각 파생 모델(교시 → 실제 시각 계산). v2 재설계가 축을
  엑셀에서 캘린더로 바꾸기로 한 상담(2026-10-31)과 맞닿아 있다.
- **`옛-v2/ops.ts` · `옛-v2/model.ts`** — 작업대(워크벤치) 문서 모델과 되돌리기 가능한 연산 설계.
- **`옛-v1/io/excel.ts`** — xlsx 왕복(가져오기/내보내기) 실제 구현.
- **`옛-v1/ui/help/`** — 도움말 체계(툴팁·정지 그림·움직이는 사용법) 전체. 문서화 패턴 참고용.

## 끌어다 쓸 때 주의

- 여기서 복사해 새 `src/` 로 가져올 땐 **파일을 그대로 옮기지 말고 필요한 부분만 다시 짠다** —
  이 폴더의 상대 import·의존 구조는 새 폴더 배치(`src/core` · `src/ui` · `src/features`)와 안 맞는다.
- `옛-v1`·`옛-v2` 둘 다 `gne-sheet`(비공개 git 의존성)·`xlsx` 를 쓰던 자리가 있다 — `package.json` 의
  해당 의존성은 지우지 않고 남겨 뒀다(새 코드가 아직 안 써도 당장 필요 없어진 게 아니라서).
